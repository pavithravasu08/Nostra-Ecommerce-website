# Nostra — Responsive E-commerce Website

Nostra is a front-end e-commerce website project built with **HTML, CSS, and JavaScript**. It is inspired by modern fashion stores and designed as a learning portfolio project.

## Pages
- `index.html` — Home page with hero banner, category cards, featured products, and newsletter form.
- `collections.html` — Product listing with live search, category filters, price filters, sorting, and an empty-results state.
- `contact.html` — Contact page with client-side form validation.
- `style.css` — Shared responsive styles and mobile layouts.
- `script.js` — Navigation, collection interactions, and form handling.

## Features
- Responsive layout for desktop, tablet, and mobile.
- Search products by name or category as you type.
- Filter products by category and price range.
- Sort by featured order, price, or product name.
- Category links on the home page open the collection with the matching filter selected.
- Mobile navigation menu.
- Contact form validation and demo newsletter interaction.
- Accessible form labels, alt text, and live feedback areas.


## Important note
This is a front-end student project. Contact and newsletter forms show browser-side feedback only; they do not store or send information to a server. Product photos are loaded from Unsplash, so an internet connection is needed for those images.
